# 架构与数据边界

AnimeWay 是一个 Streamlit 应用。公开作品与地点资料、个人行程和旅行记录分开存储。当前可规划范围是东京精选 1—3 日；全库索引用于发现，不会自动成为可信的 Trip 地点。

## 模块职责

| 路径 | 职责 |
|---|---|
| `app.py` | 初始化公开检索、私人身份和三个顶层入口；只做页面编排 |
| `components/` | 表单、预览、地图、旧资料核对和当天操作；消费 `core` 返回的结果 |
| `core/trip.py` | 唯一 Trip 计划结构、编辑规则、日程评估和执行事件语义 |
| `core/trip_transport.py` | 统一交通段结果、估算依据、未知值与过期判断 |
| `core/trip_store.py` | 私人草案、已保存 Trip、版本和当天事件的持久化 |
| `core/trip_adoption.py` | 旧清单逐项审查、转换和差异核对 |
| `core/private_store.py`、`core/journal_store.py` | 匿名身份、旧资料兼容、备份、记录与分享存储 |
| `core/map_*`、`core/public_snapshot.py` | 公开地图索引查询与快照选择 |
| `data_factory/` | 公开数据抓取、规范化、索引和离线快照构建；不接触私人 Trip |
| `scripts/` | 维护者显式执行的审核和只读审计命令 |
| `assets/` | 样式、地图和浏览器身份组件 |
| `tests/` | 按交通、草案、当天操作与旧资料兼容组织的回归用例 |

`core` 不依赖 Streamlit 页面。页面不另算交通时间、费用或行程可行性；同一份计划在草案预览、保存详情和当天清单中调用 `evaluate()`。AI 负责解释需求、选择候选地点和提出编辑操作；AI 输出仍须经过同一计划校验及评估。

## 一份 Trip 的生命周期

```text
作品、日期、交通偏好 / 地图、手册、背包选点
              ↓
          Trip 计划草案
              ↓ evaluate(plan, catalog)
          预览与人工编辑
              ↓ 用户明确保存
          同 ID 已保存 Trip
              ↓ 用户开始当天模式
          到访 / 跳过 / 关闭等事件
              ↓ evaluate(plan, catalog, events)
          剩余行程与旅行记录
```

计划保存需求、日期、地点 ID、顺序、停留、交通默认方式及单段覆盖方式；草案自动暂存，明确保存后进入已保存 Trip。保存和重新打开不改变用户选择。执行事件与规划历史分开，跳过和打开外部导航都不算到访。重新评估使用当前公开地点资料；它会提示关闭或撤下，但不会私自删改计划。当前尚未持久化“保存时交通评估快照”，因此不能把重新打开后的评估当作历史查询结果。

## 交通与事实规则

- 用户可选步行为主或公共交通为主；单段覆盖需人工指定，默认方式变化不会清除单段设置。
- 短途步行仅是带规则版本的直线距离估算；超过支持距离保持未知。
- 东京公共交通没有已验收提供方，耗时、候车、接驳和票价保持未知；未知费用不是零费用，未知时间不参与确定的完整时刻表。
- 地点关闭、撤下或不在东京精选范围时停止将其作为可用新 Trip 地点。旧手册保存的内容仍可查看，转换时以当前资料与历史原值逐项对照。
- 外部地图链接仅帮助导航；打开链接不会验证交通结果，也不会自动写入到访。

## 私人数据与旧资料

私人数据默认位于 `.animeway/private.sqlite3`，不进入 Git。匿名身份凭据在浏览器端，数据库只存摘要。`TripStore` 继承 `PrivateStore`，用户 JSON 备份不含身份凭据；未保存草案不包含在用户备份中，跨浏览器前应先保存。

旧格式手册副本不再新建或编辑；旧备份导入是恢复历史数据的兼容入口。模板和旧清单通过 `trip_adoption` 建立个人 Trip 草案。转换前列明全部原始项、缺失或重复原因、当前事实变化及未进入的项；写入前核对顺序、必去属性和停留时长。`scripts/audit_legacy_trips.py` 只读汇总现有旧副本，不输出私人内容。完整备份、升级与回退见[部署与维护](operations.md)。

## 公开数据

`knowledge_base/raw/` 是上游数据来源，`knowledge_base/pilot/tokyo.json` 是东京精选编辑资料，`knowledge_base/animeway.sqlite3` 与 `knowledge_base/index.json` 是仓库内运行所需的公开索引。线上刷新先生成候选，再审核来源、撤下、图片许可及数量变化，最后发布不可变成对快照；应用运行时不自动爬取。构建与回退命令见[部署与维护](operations.md)。
