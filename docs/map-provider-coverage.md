# 日本地区地图能力边界

核验日期：2026-07-24

AnimeWay 当前接入高德 Web 服务 API v3。根据高德官方资料：

- 高德提供海外城市编码表，并建议生产环境通过实时地理编码服务同步海外城市信息：
  <https://lbs.amap.com/api/webservice/download>
- 海外逆地理编码需要额外申请权限；海外结果可以返回国家、城市和街道，但可能不返回
  `cityCode`：
  <https://lbs.amap.com/faq/advisory/overseas-advisory/47041>
- 公交路径规划支持公交、地铁和火车，跨城请求需要起点城市和终点城市：
  <https://lbs.amap.com/api/webservice/guide/api/direction>
- 路径规划返回的 `polyline` 可以用于绘制实际道路轨迹。

官方资料没有承诺日本地区公交、铁路、步行或驾车路径的完整覆盖率，也没有提供日本城市级
SLA。因此 AnimeWay 将高德在日本的结果视为 best-effort：

1. 只有接口成功返回路线时才显示为在线路径。
2. 短距离优先步行，同城优先公交，跨城优先公交/铁路。
3. 海外城市编码或路线失败时降级为离线直线估算，并明确标注。
4. 不把离线距离、耗时或线路包装成地图服务事实。
5. 若上线面向日本用户的生产服务，应接入有明确日本覆盖承诺的本地交通 provider，
   并用真实日本样本持续测量地理编码成功率、路线成功率和路径偏差。
