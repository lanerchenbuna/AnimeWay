# 📑 项目架构书：动漫圣地巡礼智能 Agent (Anime Pilgrimage Agent)

### 1. 项目概述

本项目旨在构建一个基于**国产 AI 能力**（阿里通义千问 + 阿里多模态）与**垂直领域数据**（Anitabi + Bangumi + 高德地图）的智能助手。它可以理解用户的自然语言或图片输入，精准定位动漫场景现实坐标，并提供路径规划。

### 2. 技术栈 (Tech Stack)

* **大模型/视觉**: 阿里 DashScope (Qwen-VL-Max 用于识别，Multimodal-Embedding 用于图像比对).
* **元数据**: Bangumi API (负责将模糊的动画名转换为精确 ID).
* **巡礼数据**: Anitabi API (负责提供精确坐标和场景对比图).
* **LBS/地图**: 高德地图 Web API (负责地理编码与路径规划).
* **前端/交互**: Streamlit (快速构建 Web UI).

#### 🛠️ 模块一：健壮的 Bangumi ID 匹配

**痛点**：简单的搜索可能会搜到漫画、小说，或者同名但不同季度的作品（如《轻音少女》第一季和第二季 ID 不同）。
**优化策略**：

1. **类型过滤**：强制指定 `type=2` (动画)。
2. **名称清洗**：计算输入名与结果名的相似度（Levenshtein 距离），或优先完全匹配。

```python
import requests
from urllib.parse import quote
import difflib

def get_bangumi_id_robust(anime_name):
    """
    健壮的 Bangumi ID 获取逻辑
    """
    # type=2 表示仅搜索动画
    url = f"https://api.bgm.tv/search/subject/{quote(anime_name)}?type=2&responseGroup=medium"
    headers = {'User-Agent': 'AnimePilgrimage/1.0'}
    
    try:
        res = requests.get(url, headers=headers)
        data = res.json()
        
        if 'list' not in data or not data['list']:
            return None, None
            
        candidates = data['list']
        best_match = None
        
        # 策略1: 优先寻找中文名或原名完全一致的结果
        for item in candidates:
            cn_name = item.get('name_cn', '')
            jp_name = item.get('name', '')
            if anime_name == cn_name or anime_name == jp_name:
                return item['id'], (cn_name or jp_name)
        
        # 策略2: 如果没有完全匹配，返回排名第一的热门结果（Bangumi默认按匹配度排序）
        # 这里还可以增加模糊匹配逻辑，但 API 排序通常足够
        top_item = candidates[0]
        return top_item['id'], (top_item.get('name_cn') or top_item.get('name'))
        
    except Exception as e:
        print(f"Bangumi Search Error: {e}")
        return None, None

```

#### 👁️ 模块二：基于多模态向量的图像匹配

**痛点**：Qwen-VL 是对话模型，如果你拿 1 张用户图去和 Anitabi 里的 100 张图对话问“哪个最像”，不仅慢而且极度消耗 Token。
**最佳实践**：使用 **DashScope Multimodal Embedding (多模态向量)**。将图片转为向量，计算余弦相似度。这是工业界做“以图搜图”的标准解法。

*注：此功能需要开通阿里云 DashScope 的 `multimodal-embedding` 权限。*

```python
import dashscope
from dashscope import MultiModalEmbedding
import numpy as np
from numpy.linalg import norm

# 阿里云 DashScope API Key
dashscope.api_key = 'YOUR_ALI_API_KEY'

def calculate_cosine_similarity(vec1, vec2):
    return np.dot(vec1, vec2) / (norm(vec1) * norm(vec2))

def find_best_visual_match(user_img_url, anitabi_points):
    """
    1. 用 Qwen-VL 识别用户图片属于哪部动画（缩小范围）。
    2. 获取该动画所有 Anitabi 图片。
    3. 用 Embedding 找出视觉上最相似的场景。
    """
    
    # 步骤 1: 向量化用户的图片
    try:
        user_emb_res = MultiModalEmbedding.call(
            model="multimodal-embedding-v1",
            input=[{'image': user_img_url}]
        )
        if user_emb_res.status_code != 200:
            print("用户图片向量化失败")
            return None
        user_vec = user_emb_res.output['embedding'][0]
    except Exception as e:
        print(f"Embedding Error: {e}")
        return None

    best_score = -1
    best_point = None

    # 步骤 2 & 3: 遍历 Anitabi 的点进行比对
    # 注意：实际生产中，Anitabi 的图片向量应该预先存入向量数据库(Milvus)，而不是实时计算
    # 这里为了演示，我们只取前 5 个点进行实时计算，防止 API 超时
    
    print(f"正在对比 {len(anitabi_points[:5])} 个候选场景...")
    
    for point in anitabi_points[:5]: 
        scene_img_url = point.get('image', '').replace('plan=h160', 'plan=h360')
        if not scene_img_url: continue
        
        try:
            scene_emb_res = MultiModalEmbedding.call(
                model="multimodal-embedding-v1",
                input=[{'image': scene_img_url}]
            )
            if scene_emb_res.status_code == 200:
                scene_vec = scene_emb_res.output['embedding'][0]
                
                # 计算相似度
                score = calculate_cosine_similarity(user_vec, scene_vec)
                
                if score > best_score:
                    best_score = score
                    best_point = point
                    best_point['match_score'] = score
        except:
            continue
            
    return best_point

```
